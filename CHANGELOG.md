# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-03-01

### Added
- **Biometric Authentication**: Users can now secure the app with Fingerprint or FaceID.
- **Health Data Export**: Added support for exporting health metrics to CSV, PDF, and JSON formats.
- **AI Health Assistant**: Integrated Google Gemini AI to provide personalized health insights based on logged metrics.

### Fixed
- **Profile Page**: Resolved a type mismatch error when loading user profiles.
- **Deprecations**: Updated deprecated Flutter color methods to ensure future compatibility.

## [1.0.0] - 2026-02-23

### Added
- Initial release of CareSync.
- Core Dashboard with appointment and prescription summaries.
- Appointment scheduling and management.
- Repeat prescription tracking.
- Health metrics logging (Blood Pressure, Heart Rate, etc.).
- Local data persistence using Isar.
- NHS-inspired design system.
